# نقشهٔ خودمان (گام 5.16)

نقشهٔ فعلی پنل از سرور عمومی OpenStreetMap (`tile.openstreetmap.org`) تصویر می‌گیرد. سیاست OSM فقط استفادهٔ سبک را مجاز می‌داند و برنامه‌ای که به کاربران داده می‌شود جزو «استفادهٔ سنگین» است؛ ممکن است هر زمان مسدود شود. این پوشه نقشهٔ عراق را روی سرور خودمان می‌گذارد: رایگان، بدون محدودیت، و برچسب‌ها به زبان پنل (کردی سورانی `name:ckb`، عربی، فارسی، انگلیسی).

داده از OpenStreetMap است (ساختهٔ روزانهٔ Protomaps). فقط بخش عراق دانلود می‌شود (چند صد مگابایت)، نه کل جهان.

## نصب (روی VPS، یک بار)

1. فایل نقشه را بساز (نیاز به اینترنت سرور و Docker یا برنامهٔ `pmtiles`):

```bash
cd /opt/lifedrop && git pull
```

```bash
./deploy/map/build-map.sh
```

خروجی: `deploy/maps/iraq.pmtiles`. اگر روی سرور فایل دیگری لازم است: `MAP_BBOX="غرب,جنوب,شرق,شمال"` یا `MAP_MAXZOOM=14` (کوچک‌تر و سریع‌تر).

2. بررسی کن برچسب کردی در نقشه هست:

```bash
./deploy/map/check-kurdish.sh
```

سه شهر (هولیر، سلیمانیه، دهوک) را چاپ می‌کند. اگر همه `0` بود، در این نسخه نام کردی نیست و برچسب‌ها انگلیسی می‌شوند؛ آن‌وقت به من بگو تا نام‌ها را از OSM یا ساخت دیگر بگیریم.

3. Caddy را دوباره بالا بیاور تا فایل را از `https://<API_DOMAIN>/maps/iraq.pmtiles` بدهد:

```bash
cd deploy && docker compose up -d
```

4. در Cloudflare (Workers & Pages ← پروژهٔ پنل ← Settings ← Variables) متغیر زیر را بگذار و پنل را دوباره Deploy کن:

```text
VITE_MAP_PMTILES_URL=https://api.example.com/maps/iraq.pmtiles
```

(به‌جای `api.example.com` همان `API_DOMAIN` خودت.) تا این متغیر نباشد، پنل مثل قبل از نقشهٔ عمومی OSM استفاده می‌کند و چیزی خراب نمی‌شود.

## به‌روزرسانی نقشه

هر چند ماه یک بار `./deploy/map/build-map.sh` را دوباره اجرا کن (فایل جدید جای قبلی می‌نشیند). لازم نیست سرور یا پنل را دوباره بسازی.

## متغیرهای اختیاری پنل

- `VITE_MAP_GLYPHS_URL`، `VITE_MAP_SPRITE_URL`: فونت‌ها و آیکون‌های نقشه. پیش‌فرض از `protomaps.github.io/basemaps-assets` می‌آید (فایل‌های ثابت). برای استقلال کامل می‌شود همان پوشه را روی سرور خودمان گذاشت.

## نکته

برای اینکه پنل از نقشهٔ خودمان نمایش بدهد، مرورگر باید به `https://<API_DOMAIN>/maps/…` برسد؛ Caddy برای آدرس پنل (`PANEL_ORIGIN`) اجازهٔ CORS و Range می‌دهد.
