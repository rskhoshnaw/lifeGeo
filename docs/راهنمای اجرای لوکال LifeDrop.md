## پیش‌نیازها

یک‌بار نصب

این برنامه‌ها باید نصب باشند:

- ۱

  **Docker Desktop** — پایگاه‌داده داخل Docker اجرا می‌شود. بعد از نصب، آن را باز کن و صبر کن تا علامت سبز نشان دهد.
- ۲

  **.NET 10 SDK** — برای اجرای API و build اپ موبایل.
- ۳

  **Node.js 22 LTS** — برای پنل وب. بعد از نصب: `npm install -g pnpm`
- ۴

  **Android SDK / ADB** — برای نصب اپ روی گوشی. راحت‌ترین روش: نصب **Android Studio** (شامل adb است).
- ۵

  **MAUI Workload** — در PowerShell اجرا کن:\
  `dotnet workload install maui-android`

## رفع مشکل پورت (فقط یک‌بار)

یک‌بار اجرا

ویندوز پورت ۵۴۳۲۱ را بلاک می‌کند. این دستور را **یک‌بار** در PowerShell اجرا کن تا همیشه از پورت ۵۴۳۳ استفاده شود:

```
[System.Environment]::SetEnvironmentVariable('LIFEDROP_DB_PORT', '5433', 'User')
```

⚠️ بعد از اجرا، پنجره PowerShell را ببند و دوباره باز کن تا تغییر اعمال شود.

۳

## راه‌اندازی روزانه

هر بار

ابتدا مطمئن شو **Docker Desktop** باز است، سپس در PowerShell (داخل پوشه پروژه) اجرا کن:

```
.\scripts\local\Start-All.ps1
```

این اسکریپت به ترتیب:

- ۱

  Docker را بررسی می‌کند (اگر خاموش است روشن می‌کند)
- ۲

  دیتابیس را راه می‌اندازد (اگر migration تغییر کرده rebuild می‌کند)
- ۳

  API را در پنجره جدید باز می‌کند — پورت 5256
- ۴

  پنل وب را در پنجره جدید باز می‌کند — پورت 5273
- ۵

  مرورگر را روی پنل باز می‌کند

⏱ **اولین اجرا** چند دقیقه طول می‌کشد چون پروژه build می‌شود. دفعات بعد سریع‌تر است.

۴

## نصب اپ روی گوشی

نیاز به گوشی

- ۱

  روی گوشی اندروید برو به **تنظیمات → درباره گوشی** و ۷ بار روی «شماره Build» بزن تا Developer Options فعال شود.
- ۲

  برو به **Developer Options** و **USB Debugging** را روشن کن.
- ۳

  گوشی را با کابل USB به کامپیوتر وصل کن. روی گوشی گزینه **Allow** را تأیید کن.
- ۴

  در PowerShell اجرا کن:

```
.\scripts\local\Run-Android.ps1
```

این اسکریپت اتصال USB را تنظیم می‌کند (`adb reverse`)، اپ را build و روی گوشی نصب می‌کند.

⏱ **اولین build** ۵ تا ۱۵ دقیقه طول می‌کشد.

۵

## ورود و شروع شیفت

هر بار

**پنل وب** — http://localhost:5273

| کد شرکت | `dev` |
| --- | --- |
| ایمیل مدیر | `manager@dev.local` |
| رمز | `LifeDrop-Local-1` |

**اپ موبایل**

- ۱

  کد شرکت: `dev` → ایمیل: `rep1@dev.local` → رمز: `LifeDrop-Local-1`
- ۲

  دکمه **ثبت گوشی** را بزن
- ۳

  در پنل وب، تب **Devices** → گوشی را پیدا کن → **Approve**
- ۴

  در اپ وارد شو → دکمه **شروع شیفت**
- ۵

  دسترسی به مکان را در اپ تأیید کن (**Allow while using app**)

📍 نقشه زنده هر **۳ دقیقه** یک‌بار بروزرسانی می‌شود.

۶

## حساب‌های آزمایشی

مرجع

| نقش | ایمیل | رمز |
| --- | --- | --- |
| مدیر | `manager@dev.local` | `LifeDrop-Local-1` |
| نماینده ۱ | `rep1@dev.local` | `LifeDrop-Local-1` |
| نماینده ۲ | `rep2@dev.local` | `LifeDrop-Local-1` |

کد شرکت برای همه: `dev`

۷

برای نصب دوبارە اپ روی موبایل چه دستوری را به پاورشل بدهیم؟

این دستور را اجرا کن:
.\scripts\local\Run-Android.ps1
این اسکریپت:

adb reverse می‌زند تا موبایل به API لوکال (127.0.0.1:5256) وصل شود
اپ را build می‌کند و مستقیم روی گوشی نصب و اجرا می‌کند
پیش‌نیاز: گوشی با USB به کامپیوتر وصل باشد و USB Debugging فعال باشد.
